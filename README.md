#  Project : Number Guessing Game

##  About the Project

**Objective** : Build a command-line number guessing game using Bash and PostgreSQL. This project is part of FreeCodeCamp’s Relational Database Certification and is completed in a Linux environment with shell scripting and SQL.

The game stores user data and tracks the number of attempts for each session. It interacts with a PostgreSQL database to record usernames, games played, and performance.

##  Project Tasks

- Create a PostgreSQL database named `number_guess`
- Define a `users` table to store usernames and a `games` table to store game statistics
- Write a shell script that:
  - Prompts the user for a username
  - Greets returning users and shows their game history
  - Generates a random number between 1 and 1000
  - Prompts the user to guess the number
  - Validates input (must be an integer)
  - Tracks the number of attempts
  - Inserts game results into the database
  - Displays a success message with stats
- Pass all automated tests provided by CodeRoad
